渐变 + 毛玻璃（Glassmorphism）方向 · 3 个概念 · 尺寸 / 明暗 / 灰度托盘适配测试

概念 A · 双通道汇流

HTTP(S) 与 SOCKS 两条通道交叉穿过中央代理节点 —— 保留现有「汇流」隐喻，升级为玻璃质感。白色通道 = HTTP，青色通道 = SOCKS。

主方案

蓝→靛→紫渐变底 + 玻璃节点

双通道交叉 + 中央玻璃节点，箭头指示「写入环境变量、向外生效」的方向性。节点毛玻璃高光呼应 Win11 Fluent。

概念 B · 玻璃拨杆（开关隐喻）

程序核心是「一键启用 / 停用」—— 毛玻璃滑轨 + 发光拨杆，ON 位绿色辉光直接对应托盘绿色角标。

主方案

靛蓝渐变底 + 玻璃滑轨

左侧三道短划线代表写入的环境变量（HTTP_PROXY / HTTPS_PROXY / ALL_PROXY），拨杆在 ON 位 + 绿色辉光 = 代理已启用。

概念 C · 轨道路由

中央玻璃核心 + 双交叉轨道 = 请求被代理核心接管并转发；轨道上的光点如同流动的数据包。

主方案

靛蓝渐变底（同概念B）+ 玻璃核心

轨道交叉造型独特、不依赖箭头；四颗光点示意双通道上流动的请求，中央玻璃球即代理核心。
